- Main name/title heading: 16 pt.

- Body text: 12 pt.
- Line spacing: 1.5.
- Paragraphs should be justified where appropriate.
- Avoid awkward word spacing caused by justification. If a short line would create an ugly gap, use sensible formatting rather than forcing justification.
- Keep headings with the content they introduce. A heading must never be stranded as the last meaningful line on a page. Move it to the next page when necessary so it is accompanied by body content.
